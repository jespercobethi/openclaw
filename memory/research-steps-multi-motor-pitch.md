## 第二阶段：系统建模与MPC控制器设计（第4~6月）

### 2.1 多电机驱动变桨系统动力学建模（第4~5月）

#### 目标
建立双电机驱动变桨系统的完整数学模型。

#### 步骤
1. **单台PMSM数学模型**
   - 在dq坐标系下建立电压方程：
     ```
     ud = Rs·id + Ld·(did/dt) - ωe·Lq·iq
     uq = Rs·iq + Lq·(diq/dt) + ωe·Ld·id + ωe·ψf
     ```
   - 电磁转矩方程：
     ```
     Te = (3/2)·p·[ψf·iq + (Ld - Lq)·id·iq]
     ```
   - 机械运动方程：
     ```
     J·(dωm/dt) = Te - TL - B·ωm
     ```
   - 电机参数：参考李晓凤(2019)的22kW IPMSM参数

2. **双电机耦合模型**
   - 假设两台电机通过齿轮传动机构驱动同一叶片
   - 建立耦合关系：
     ```
     θ_pitch = (θ1 + θ2) / 2  （桨距角为两电机角度的平均）
     Δθ = θ1 - θ2  （同步误差）
     ```
   - 负载模型：风载荷引起的阻力矩 TL = f(θ_pitch, v_wind)

3. **风速模型**
   - 平均风速 + 湍流分量 + 阵风分量
   - Kaimal湍流功率谱
   - 使用Simulink的Signal Builder或Wind Turbine Blockset

4. **系统状态空间模型**
   - 状态变量：x = [id1, iq1, ωm1, θ1, id2, iq2, ωm2, θ2, θ_pitch]^T
   - 输入变量：u = [ud1, uq1, ud2, uq2]^T
   - 输出变量：y = [θ_pitch, Δθ, ωm1, ωm2]^T
   - 写成状态空间形式：ẋ = f(x, u), y = g(x, u)

#### 产出
- 完整的系统数学模型文档
- Simulink系统模型（未加控制器的开环模型）

### 2.2 MPC协同控制器设计（第5~6月）

#### 目标
设计适用于双电机驱动变桨系统的MPC协同控制器。

#### 步骤
1. **线性化与离散化**
   - 在工作点处对非线性模型进行线性化
   - 采用前向欧拉法或零阶保持器进行离散化
   - 得到离散状态空间模型：x(k+1) = Ad·x(k) + Bd·u(k)

2. **目标函数设计**
   ```
   J = Σ[ ||x(k+i|k) - xref||²Q + ||u(k+i-1|k)||²R + ||Δu(k+i-1|k)||²S ]
   ```
   其中：
   - Q矩阵：跟踪误差权重（桨距角跟踪精度）
   - R矩阵：控制量权重（能耗）
   - S矩阵：控制量变化率权重（平滑性）
   - 额外项：同步误差 Δθ 的权重

3. **约束条件设定**
   - 电机力矩约束：Te_min ≤ Te ≤ Te_max
   - 电机转速约束：0 ≤ ωm ≤ ωm_max
   - 变桨角速率约束：|dθ_pitch/dt| ≤ 10°/s
   - 桨距角范围：0° ≤ θ_pitch ≤ 90°
   - 控制量约束：u_min ≤ u ≤ u_max

4. **预测模型**
   - 预测时域 Np = 20（约2秒）
   - 控制时域 Nc = 5
   - 采样周期 Ts = 0.1s

5. **QP求解**
   - 使用MATLAB的quadprog函数或MPC Toolbox
   - 每个采样时刻求解一次QP问题
   - 输出：最优控制序列 u*(k), u*(k+1), ..., u*(k+Nc-1)
   - 执行第一个控制量 u*(k)

6. **风速预测前馈**
   - 使用ARIMA或简单线性预测模型
   - 预测未来1-2秒的风速
   - 将预测风速作为MPC的已知扰动输入

#### 产出
- MPC控制器的MATLAB代码
- Simulink控制模型（含MPC控制器）

### 3.2 工况仿真与性能验证（第7~8月）

#### 目标
在多种工况下验证MPC控制器的性能。

#### 步骤
1. **工况1：额定风速稳态**
   - 风速：12m/s（恒定）
   - 验证：桨距角跟踪精度、稳态同步误差
   - 评价指标：跟踪误差 ≤ 0.5°，同步误差 ≤ 0.3°

2. **工况2：阵风冲击**
   - 风速：12m/s → 突变至17m/s → 恢复12m/s
   - 验证：变桨响应速度、超调量
   - 评价指标：调节时间、超调量

3. **工况3：湍流连续扰动**
   - 风速：平均12m/s + Kaimal湍流
   - 验证：长时间运行的稳定性、跟踪精度
   - 评价指标：跟踪误差的均方根（RMSE）

4. **工况4：单电机故障降级**
   - 模拟电机1在t=5s时力矩降至50%
   - 验证：系统的冗余能力和故障容忍性
   - 评价指标：故障后桨距角偏差、恢复时间

5. **工况5：参数不确定性**
   - 电机参数（Rs, Ld, Lq）±20%偏差
   - 验证：MPC的鲁棒性

#### 产出
- 各工况的仿真结果数据
- 性能指标对比表

---

### 3.3 对比分析与总结（第8~9月）

#### 目标
与传统控制方法进行系统对比，总结MPC的优势。

#### 步骤
1. **与ADRC+偏差耦合对比**
   - 在相同工况下运行两种控制器
   - 对比指标：跟踪精度、同步误差、调节时间、能耗
   - 绘制对比图表

2. **与PID+主从控制对比**
   - 同样进行各工况仿真
   - 重点对比：阵风冲击和湍流工况下的性能差异

3. **结果分析**
   - MPC在哪些工况下有明显优势？
   - MPC的计算开销是否可接受？
   - 约束处理能力的实际效果

4. **敏感性分析**
   - 预测时域Np的影响
   - 权重矩阵Q、R、S的影响
   - 风速预测精度对控制效果的影响

#### 产出
- 对比分析报告（含图表）
- MPC参数调优指南
