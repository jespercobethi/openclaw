# 双驱变桨MPC仿真实验总结

> 日期：2026-06-03
> 项目：基于多电机驱动的大型风电变桨伺服系统研究

---

## 一、项目背景

校级研究生科研创新项目，目标是设计基于MPC的双驱变桨伺服系统协同控制器，与传统PID和ADRC方案进行对比，验证MPC在风电变桨控制中的优势。

**系统参数：**
- 电机：22kW IPMSM（Rs=0.031Ω, Ld=3.55mH, Lq=3.72mH, ψf=0.348Wb, p=3）
- 传动比：i=800
- 叶片惯量：8000 kg·m²
- 齿轮刚度：k_g=2×10⁵ N·m/rad
- 额定风速：12 m/s，额定转速：1500rpm

## 三、仿真结果

### 性能指标对比（15°→20°阶跃，80s仿真）

| 指标 | MPC | PID | ADRC |
|------|-----|-----|------|
| 上升时间(s) | 39.59 | 43.69 | 39.61 |
| 超调量(%) | 1.01 | 0.87 | 1.01 |
| 调节时间(s) | 48.50 | 48.35 | 48.51 |
| 同步误差(°) | 2.67 | 0 | 0 |

### 结论
1. **MPC和ADRC**响应最快（~39.6s），PID稍慢（43.7s）
2. **超调量**三者都很小（<1.1%），满足工程要求
3. **同步误差**：PID/ADRC通过偏差耦合实现完美同步（0°）；MPC通过软约束实现近似同步（2.67°）
4. **调节时间**三者接近（~48.5s），差异不大

## 四、调试过程与踩坑记录

### 🔴 问题1：前向欧拉步长太大（10ms）
- **现象**：所有状态冻结，θ不变化，控制器输出锁死
- **原因**：电气时间常数τ=L/R≈0.11s，10ms步长接近稳定性极限
- **解决**：改用定步长RK4（1ms）

### 🔴 问题2：缺少气动负载力矩
- **现象**：风速变化时桨距角无响应
- **原因**：状态方程中没有气动转矩项，风速对系统无影响
- **解决**：加入 T_aero = P_aero/ω/i_ratio

### 🔴 问题3：工作点不匹配
- **现象**：MPC桨距角跑到115°
- **原因**：初始θ=0（桨距0°），但参考是15°，电机需转12000rad
- **解决**：初始化θ=15°×i_ratio，从正确工作点出发

### 🔴 问题4：增广状态MPC积分项发散
- **现象**：MPC pitch发散到70-200°，QP返回dU=0
- **原因**：增广状态的积分项导致步阶响应矩阵条件数极差（RCOND~1e-23）
- **解决**：去掉增广状态，用标准8维状态空间MPC

### 🔴 问题5：PID误差在电机侧弧度计算
- **现象**：PID输出仅0.37V，无法驱动电机
- **原因**：误差β_ref/i_ratio=0.00025rad，Kp=1500乘出来太小
- **解决**：误差在输出侧角度（°）计算 + Vq0前馈

### 🔴 问题6：LQR求解失败
- **现象**：Riccati方程无解，K矩阵无穷大
- **原因**：增广系统有不可控模态
- **解决**：改用pinv直接求解，去掉LQR

### 🟡 问题7：tune_mpc.m所有参数结果相同
- **现象**：16组Np/Nc结果完全一样
- **原因**：simulate_step内部调用setup_params覆盖了参数
- **解决**：重构为参数传递方式
