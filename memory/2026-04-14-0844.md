这是用 OpenRouter SDK 进行流式对话并获取思考 token 的代码。逐段解释：

---

**初始化**
```javascript
const openrouter = new OpenRouter({
  apiKey: "<OPENROUTER_API_KEY>"
});
```
创建一个 OpenRouter 客户端实例，需要填入你的 API Key。

---

**发送请求（流式）**
```javascript
const stream = await openrouter.chat.send({
  model: "google/gemma-4-26b-a4b-it:free",  // 免费模型
  messages: [{ role: "user", content: "How many r's are in 'strawberry'?" }],
  stream: true  // 开启流式输出
});
```
- `stream: true` 表示服务端会一块一块返回数据，而不是等全部生成完再返回
- 适合聊天机器人这种需要"打字机效果"的场景

---

**逐块处理响应**
```javascript
let response = "";
for await (const chunk of stream) {
  const content = chunk.choices[0]?.delta?.content;
  if (content) {
    response += content;
    process.stdout.write(content);  // 实时打印到终端
  }
  if (chunk.usage) {
    console.log("Reasoning tokens:", chunk.usage.reasoningTokens);
  }
}
```
- `for await...of` 遍历流中的每个数据块
- `chunk.choices[0]?.delta?.content` 是流式输出的文本内容
- `process.stdout.write(content)` 实时打印，不需要换行
- `chunk.usage.reasoningTokens` 是**思考 token 数量**（模型推理时消耗的 token）

---

**关键点：这个代码有什么用？**

1. **流式输出** — 用户可以看到模型"一边想一边说"的效果，而不是等几秒才显示全部
2. **计算思考 token** — `reasoningTokens` 反映模型内部推理消耗了多少 token，Gemma 4 这个模型支持单独统计推理过程的开销
3. **累积完整回复** — `response` 变量把流式内容拼接成完整字符串，供后续使用
