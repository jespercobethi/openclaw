### MPC目标函数设计
```
J = Σ[ Q·||θpitch - θref||² + R·||Δu||² + S·||θ1 - θ2||² ]

```

| 10-12 | 全系统联调：MPC+同步+前馈 | 跑全部工况，收集数据 |

### LSTM代码框架（Python/PyTorch）
```python
import torch
import torch.nn as nn

class WindLSTM(nn.Module):
    def __init__(self):
        super().__init__()
        self.lstm = nn.LSTM(input_size=1, hidden_size=64, 
                           num_layers=2, batch_first=True)
        self.fc = nn.Linear(64, 1)
    
    def forward(self, x):
        # x: (batch, seq_len=30, 1) - 过去30个风速采样点
        out, _ = self.lstm(x)
        return self.fc(out[:, -1, :])  # 输出未来1个时刻的风速预测
```

### 风速数据生成（MATLAB）
```matlab
% Kaimal湍流风谱
f = 0.01:0.01:10;  % 频率范围
S_kaimal = 4 * sigma^2 * L / ((1 + 6*f*L/V_hub)^1.5) ./ f;
% 生成时域风速序列
v_wind = v_mean + ifft(sqrt(S_kaimal .* df)) .* randn(size(f));
```

### 关键动作
- LSTM不用太复杂，2层LSTM + 1层全连接就够
- 先用Python训练模型，导出权重，在MATLAB里调用
- 预测精度不用特别高，MPC本身有反馈校正，前馈只是锦上添花
