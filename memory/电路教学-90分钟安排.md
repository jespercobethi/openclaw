# 电路考点精讲 · 90分钟教学计划

> 创建时间：2026-05-18
> 用途：考研电路课程教学参考

---

## 第1讲：电路模型和电路定律（约50分钟）

| 时间 | 内容 | 重点/考点 |
|------|------|-----------|
| 0-5min | 电路模型、理想元件概述 | 4种基本元件的物理意义 |
| 5-15min | 电流/电压的参考方向 | ⭐ 参考方向的选取、关联/非关联判断 |
| 15-22min | 功率的计算与判断 | 关联→P=ui吸收，非关联→P=ui发出 |
| 22-30min | 电阻元件 + 欧姆定律 | u=Ri（关联），u=-Ri（非关联） |
| 30-38min | 电容元件 | i=C·du/dt，隔直通交，储能W=½Cu² |
| 38-45min | 电感元件 | u=L·di/dt，直流短路，储能W=½Li² |
| 45-50min | 独立电源 + 受控源 | 4种受控源（CCCS/VCCS/VCVS/CCVS） |

**穿插例题**：参考方向判断 + 功率计算（建议2-3道）

---

## 第2讲：电阻电路的等效变换（约40分钟）

| 时间 | 内容 | 重点/考点 |
|------|------|-----------|
| 50-55min | 电阻串联并联 | 分压分流公式 |
| 55-65min | Δ-Y 变换 | ⭐ 变换公式（简记法）+ 桥式电路 |
| 65-72min | 电源串并联 | 电压源只能同值并联，电流源只能同值串联 |
| 72-80min | 电压源↔电流源等效变换 | ⭐ iₛ=uₛ/R，方向、内部不等效 |
| 80-90min | 输入电阻计算 | 外加电源法（含受控源的情况） |

**穿插例题**：Δ-Y变换化简 + 电源等效变换（建议2-3道）

---

## 📝 教学建议

1. **第1讲是基础**，参考方向和KCL/KVL必须讲透，后面全靠这个
2. **重点突出3个公式**：
   - 欧姆定律 u=Ri（注意关联方向）
   - 电容 i=C·du/dt、电感 u=L·di/dt
   - 电源等效变换 iₛ=uₛ/R
3. **考研高频考点**：
   - 参考方向判断 + 功率正负
   - Δ-Y 变换（桥式电路必考）
   - 电源等效变换化简电路
   - 含受控源的输入电阻
4. **节奏控制**：理论讲完立刻跟一道例题，考研学生最需要的是解题套路
