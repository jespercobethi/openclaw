## 90分钟教学安排

### 第一部分：第3讲 电阻电路的一般分析（约40分钟）

#### 1. 网络图论基础速览（5分钟）
- 图、支路、节点、树、连支、基本回路
- **重点**：KCL独立方程数 = n-1，KVL独立方程数 = b-(n-1)
- 不用展开讲图论细节，点到为止

#### 2. 支路电流法（8分钟）
- 方法：以所有支路电流为未知量，列n-1个KCL + b-(n-1)个KVL
- **步骤总结**：
  1. 设定各支路电流参考方向
  2. 列n-1个KCL方程
  3. 列b-(n-1)个KVL方程（含元件VCR）
  4. 联立求解
- **快速过1道例题**（例1即可），让学生掌握基本流程
- **考试要点**：支路多时方程多，不是最优方法，但要会用

#### 3. 回路电流法 / 网孔电流法（12分钟）
- **核心思想**：假想电流在回路中流动，自动满足KCL
- **自电阻、互电阻**概念（重点讲！）
  - 自电阻Rii：回路i所有电阻之和（恒正）
  - 互电阻Rij：两回路共用电阻（同向取正，反向取负）
- **标准方程**：R11·i1 + R12·i2 + ... = uS11
- **特殊情况处理**（考点！）：
  - 理想电流源处理：①只让一个回路经过 ②设电压增补方程
  - 受控源处理：先当独立源列方程，再补控制量关系
- **讲1-2道典型例题**（例1、例3）

#### 4. 节点电压法（15分钟）
- **核心思想**：以节点电压为未知量，自动满足KVL
- **自电导、互电导**概念（重点讲！）
  - 自电导Gii：连接节点i的所有电导之和（恒正）
  - 互电导Gij：两节点间电导之和（取负值）
- **标准方程**：G11·u1 + G12·u2 + ... = iS11
- **特殊情况处理**（高频考点！）：
  - 理想电压源支路：①选电压源一端为参考点 ②设电流增补方程
  - 受控源处理：先当独立源，再补控制量关系
  - 无伴电压源（两端都不接地）的处理
- **讲1-2道典型例题**（例1、例5）
- **考试技巧**：节点法比回路法更常用，优先掌握

### 第二部分：第4讲 电路定理（约45分钟）

#### 5. 叠加定理（12分钟）
- **定理内容**：线性电路中，任一支路电流/电压 = 各独立源单独作用的代数和
- **使用要点**（必强调！）：
  - ✅ 适用于电流、电压（线性量）
  - ❌ **不适用于功率**（功率是二次函数）
  - "单独作用"= 其余电压源短路、电流源开路
  - 受控源**不能单独作用**，始终保留
- **典型题型**：
  - 直接用叠加定理求解
  - 已知某电源作用结果，求另一电源作用结果（例5、例6）
  - 灵活应用：改变某电源值后求新响应（例7）
- **讲2-3道例题**

#### 6. 替代定理（5分钟）
- **简要说明**：已知支路可用等效电压源/电流源/电阻替代
- **考试定位**：了解即可，不是高频考点
- **强调**：替代 ≠ 等效变换（替代前后电路拓扑不变）
- 快速过1道例题

#### 7. 戴维南定理（15分钟）⭐ 重点中的重点
- **定理内容**：任何线性有源一端口网络 → 电压源 + 串联电阻
  - Uoc = 开路电压
  - Req = 独立源置零后的等效电阻
- **求Uoc的方法**：
  - 开路端口电压（直接求或用叠加/节点/回路法）
- **求Req的方法**（3种，都要讲！）：
  - ① 串并联化简（无受控源时）
  - ② 外加电源法（有受控源时）：端口加电压U，求电流I，Req = U/I
  - ③ 短路电流法：Req = Uoc / Isc
- **典型应用**：求某一支路的电流/电压/功率
- **讲2-3道经典例题**（例1、例3、例4.1）
- **考试提醒**：几乎每年必考！

#### 8. 诺顿定理（5分钟）
- **定理内容**：任何线性有源一端口网络 → 电流源 + 并联电导
  - Isc = 短路电流
  - Geq = 独立源置零后的等效电导
- **与戴维南的关系**：电源等效变换即可互转
- **快速过1道例题**
- **考试定位**：掌握原理，会和戴维南互转即可

#### 9. 最大功率传输定理（8分钟）⭐
- **定理内容**：当 RL = Req（负载电阻 = 等效内阻）时，负载获得最大功率
  - Pmax = Uoc² / (4Req)
- **解题步骤**：
  1. 断开负载，求戴维南等效电路（Uoc、Req）
  2. 令 RL = Req
  3. 计算 Pmax = Uoc² / (4Req)
- **典型例题**：RL为何值时获最大功率，并求Pmax
- **考试提醒**：常与戴维南定理联合出题！

### 第三部分：总结与答疑（5分钟）

#### 核心公式速查表

| 方法/定理 | 核心公式 | 适用场景 |
|-----------|---------|---------|
| 支路电流法 | KCL + KVL联立 | 简单电路 |
| 回路电流法 | Rii·ii + ΣRij·ij = uSii | 平面电路，网孔少 |
| 节点电压法 | Gii·ui + ΣGij·uj = iSii | 节点少的电路 |
| 叠加定理 | i = i(1) + i(2) + ... | 多电源电路 |
| 戴维南定理 | Uoc + Req串联 | 求某一支路响应 |
| 诺顿定理 | Isc并联Geq | 与戴维南互转 |
| 最大功率传输 | RL = Req, Pmax = Uoc²/(4Req) | 负载匹配问题 |

#### 考研重点提醒
1. **节点电压法** — 最常用，必熟练
2. **戴维南定理** — 几乎必考，三种求Req方法都要会
3. **叠加定理** — 注意功率不能叠加
4. **最大功率传输** — 常与戴维南联合出题
5. 受控源处理 — 以上所有方法都要会处理受控源
