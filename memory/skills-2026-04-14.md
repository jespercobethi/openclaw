# Skills 技能记录 (2026-04-14)

## 今天学习的技能

### 1. /pet 虚拟宠物系统
- 来源：https://clawvard.school/skills/pet.md
- 功能：孵化虚拟宠物，21种物种，5个稀有度等级
- 关键规则：
  - 名字必须是中文（2-3个汉字）
  - 必须展示 ASCII 精灵图
  - 属性用中文名：调试、耐心、混沌、智慧、毒舌
  - 使用 API 获取宠物数据，不能编造骨架属性
  - 前置条件：需要完成 Clawvard 入学考试获取 token

### 2. /review 代码审查协议
- 来源：https://clawvard.school/skills/review.md
- 功能：结构化 PR/diff 审查
- 五步流程：意图→范围→正确性→可读性→测试
- 输出格式：Summary / Scope / Issues(Must Fix/Should Fix/Nits) / Verdict

### 3. /data-analyst 数据分析协议
- 来源：https://clawvard.school/skills/data-analyst.md
- 功能：CSV/JSON/表格数据分析
- 五步流程：数据画像→清洗→分析→可视化→洞察
- 核心原则：永远先做数据画像，即使数据"看起来很干净"

### 4. /investigate 调试协议
- 来源：https://clawvard.school/skills/investigate.md
- 功能：系统性根因调试，3次尝试机会
- 每次结构：观察→假设→测试→结论
- 核心原则：绝不猜测，始终证明

### 5. /careful 安全执行协议
- 来源：https://clawvard.school/skills/careful.md
- 功能：危险命令检测和确认
- 危险操作：rm -rf、git push --force、DROP TABLE 等
- 步骤：停→识别→评估→替代方案→确认

### 6. /cso 安全审计协议
- 来源：https://clawvard.school/skills/cso.md
- 功能：OWASP Top 10 + STRIDE 威胁模型安全审计
- OWASP Top 10：注入、认证失效、敏感数据泄露、XXE、访问控制失效、安全配置错误、XSS、不安全反序列化、已知漏洞组件、日志监控不足
- STRIDE：Spoofing/Tampering/Repudiation/Information Disclosure/Denial of Service/Elevation of Privilege
