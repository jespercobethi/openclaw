## 一、PMSM dq坐标系数学模型

### 1.1 电压方程

**d轴电压方程：**
```
ud = Rs·id + Ld·(did/dt) - p·ωm·Lq·iq
```

**q轴电压方程：**
```
uq = Rs·iq + Lq·(diq/dt) + p·ωm·Ld·id + p·ωm·ψf
```

其中：
- ud, uq：d、q轴电压 [V]
- id, iq：d、q轴电流 [A]
- Rs：定子电阻 [Ω]
- Ld, Lq：d、q轴电感 [H]
- ψf：永磁体磁链 [Wb]
- p：极对数
- ωm：机械角速度 [rad/s]

### 1.2 电磁转矩方程

```
Te = (3/2)·p·[ψf·iq + (Ld - Lq)·id·iq]
```

对于IPMSM（内置式），Ld ≠ Lq，存在磁阻转矩分量。

### 1.3 机械运动方程

```
J·(dωm/dt) = Te - TL - B·ωm
```

其中：
- J：转动惯量 [kg·m²]
- TL：负载转矩 [N·m]（包含风载荷 + 齿轮摩擦）
- B：粘性摩擦系数 [N·m·s/rad]

### 1.4 角度关系

```
dθ/dt = ωm
```

## 三、双电机耦合传动模型

### 3.1 传动链结构

```
电机1 → 减速齿轮 → 行星齿轮 → 叶片桨距角
电机2 → 减速齿轮 ↗
```

每片叶片由2台电机通过齿轮啮合共同驱动。

### 3.2 双电机耦合方程

**电机1：**
```
J1·(dω1/dt) = Te1 - (1/i)·Tg12 - B1·ω1
```

**电机2：**
```
J2·(dω2/dt) = Te2 - (1/i)·Tg21 - B2·ω2
```

**齿轮啮合转矩：**
```
Tg12 = kg·(θ1/i - θ2/i) + cg·(ω1/i - ω2/i)
Tg21 = -Tg12（牛顿第三定律）
```

**叶片侧：**
```
Jblade·(dωblade/dt) = Tg12 + Tg21 - Taero
```

其中：
- i：减速比（典型值 1000~1500，参考李奔论文变桨机构）
- kg：齿轮啮合刚度 [N·m/rad]
- cg：齿轮啮合阻尼 [N·m·s/rad]
- Jblade：叶片等效转动惯量 [kg·m²]
- Taero：气动阻力矩 [N·m]

### 3.3 传动参数（需确认）

| 参数 | 符号 | 典型值 | 来源 |
|------|------|--------|------|
| 减速比 | i | 1000~1500 | 李奔论文/风机手册 |
| 齿轮啮合刚度 | kg | 1×10⁵ N·m/rad | 齿轮传动手册 |
| 齿轮啮合阻尼 | cg | 500 N·m·s/rad | 经验值 |
| 叶片转动惯量 | Jblade | 5000~15000 kg·m² | 取决于叶片长度 |

## 四、风载荷模型

### 4.1 Kaimal湍流风速模型

**功率谱密度：**
```
S(f) = (4·σ²·L/v̄) / (1 + 6·f·L/v̄)^(5/3)
```

其中：
- σ：湍流标准差 = TI × v̄（TI为湍流强度，典型值0.12~0.18）
- L：湍流积分尺度（典型值 340.2m，IEC 61400标准）
- v̄：平均风速 [m/s]
- f：频率 [Hz]

**生成方法：** 用逆傅里叶变换法（Shinozuka方法）或直接用MATLAB的` dsp.ColoredNoise`生成。

### 4.2 阵风模型

**斜坡阵风（用于工况测试）：**
```
v(t) = v0 + Δv·(t - t0)/(t1 - t0),  t0 ≤ t ≤ t1
v(t) = v0 + Δv,                        t1 < t ≤ t2
v(t) = v0 + Δv·(t2 - t)/(t2 - t1),    t2 < t ≤ t3
```

典型参数：v0=12m/s, Δv=5m/s, t0=5s, t1=10s, t2=15s, t3=20s

## 五、气动阻力矩公式

### 5.1 风轮气动转矩

```
Taero = (1/2)·ρ·A·R·v³·Cp(λ,β) / ωr
```

简化为桨距角控制模型（以桨距角β为控制量）：

```
TL = (1/2)·ρ·π·R²·v³·Cp(λ,β) / (i·ωm)
```

### 5.2 Cp近似公式（查表或拟合）

```
Cp(λ,β) = c1·(c2/λi - c3·β - c4)·exp(-c5/λi) + c6·λ
```

其中：
```
1/λi = 1/(λ + 0.08·β) - 0.035/(β³ + 1)
```

典型系数（Heier模型）：
- c1 = 0.5176, c2 = 116, c3 = 0.4, c4 = 5, c5 = 21, c6 = 0.0068

### 5.3 参数汇总

| 参数 | 符号 | 数值 | 单位 |
|------|------|------|------|
| 空气密度 | ρ | 1.225 | kg/m³ |
| 风轮半径 | R | ~50（需确认） | m |
| 叶尖速比 | λ | 6~8（最优） | - |
| 桨距角范围 | β | 0°~90° | ° |
| 变桨角速率限制 | dβ/dt | ≤10 | °/s |

## 六、完整状态空间方程（8状态）

### 6.1 状态向量定义

```
x = [id1, iq1, ω1, θ1, id2, iq2, ω2, θ2]ᵀ
```

- id1, iq1：电机1的d/q轴电流
- ω1, θ1：电机1的角速度和角度
- id2, iq2：电机2的d/q轴电流
- ω2, θ2：电机2的角速度和角度

### 6.2 控制输入

```
u = [ud1, uq1, ud2, uq2]ᵀ
```

### 6.3 扰动输入

```
w = [TL]  （气动负载转矩，含风速扰动）
```

### 6.4 非线性状态方程

```
ẋ = f(x, u, w)
```

展开：

```
did1/dt = (-Rs·id1 + p·ω1·Lq1·iq1 + ud1) / Ld1
diq1/dt = (-Rs·iq1 - p·ω1·Ld1·id1 - p·ω1·ψf1 + uq1) / Lq1
dω1/dt = [(3/2)·p·(ψf1·iq1 + (Ld1-Lq1)·id1·iq1) - (1/i)·Tg12 - B1·ω1] / J1
dθ1/dt = ω1

did2/dt = (-Rs·id2 + p·ω2·Lq2·iq2 + ud2) / Ld2
diq2/dt = (-Rs·iq2 - p·ω2·Ld2·id2 - p·ω2·ψf2 + uq2) / Lq2
dω2/dt = [(3/2)·p·(ψf2·iq2 + (Ld2-Lq2)·id2·iq2) - (1/i)·Tg21 - B2·ω2] / J2
dθ2/dt = ω2
```

其中：
```
Tg12 = kg·(θ1/i - θ2/i) + cg·(ω1/i - ω2/i)
Tg21 = -Tg12
```

### 6.5 输出方程

```
y = [ω1, ω2, θ1/i, θ2/i, Te1, Te2]ᵀ
```

## 七、工作点线性化

### 7.1 选取工作点

假设额定工况下稳态运行：
- v̄ = 12 m/s（额定风速）
- β₀ = 某个稳态桨距角（由功率平衡确定）
- ω₀ = 额定角速度
- id0 = 0（id=0控制策略）
- iq0 = 由负载转矩确定

### 7.2 线性化过程

在工作点 (x₀, u₀, w₀) 处泰勒展开：

```
ẋ ≈ A·(x - x₀) + B·(u - u₀) + Bw·(w - w₀)
```

其中：
```
A = ∂f/∂x |(x₀,u₀,w₀)    （8×8 状态矩阵）
B = ∂f/∂u |(x₀,u₀,w₀)    （8×4 输入矩阵）
Bw = ∂f/∂w |(x₀,u₀,w₀)   （8×1 扰动矩阵）
```

### 7.3 各偏导数矩阵（简化表达）

由于电机1和电机2结构对称，A矩阵具有块结构：

```
A = [A11  A12]
    [A21  A22]
```

其中 A11、A22 为各电机自身的状态矩阵（4×4），A12、A21 为耦合项。

## 八、离散化（前向欧拉，Ts=0.1s）

### 8.1 离散化方法

**前向欧拉：**
```
x(k+1) = x(k) + Ts·ẋ(k) = (I + Ts·A)·x(k) + Ts·B·u(k) + Ts·Bw·w(k)
```

即：
```
Ad = I + Ts·A
Bd = Ts·B
Bwd = Ts·Bw
```

### 8.2 离散状态方程

```
x(k+1) = Ad·x(k) + Bd·u(k) + Bwd·w(k)
```

### 8.3 离散化注意事项

- Ts = 0.1s 对于电流环（电气时间常数 L/R ~ 20ms）偏大
- 建议：**电流环用更小的Ts（如0.001s），速度环用Ts=0.1s**
- 或者：对电气子系统用双线性变换（Tustin），机械子系统用前向欧拉
- 验证：检查 Ad 矩阵特征值是否在单位圆内（稳定性条件）
