# 2026-06-11 MPC调参调试

## 今日进展

### 核心bug修复
1. **`dual_motor_dynamics` 缺少 `- Ta` 项** — 这是所有问题的根源
   - mpc_controller.m 的局部函数 dw1/dt 公式漏掉了气动转矩 Ta
   - 导致平衡点 dw/dt=825.47（应为0），线性化产生不稳定特征值
   - 修复：创建独立文件 `pitch_dynamics.m`，删除 mpc_controller.m 的局部函数

2. **平衡点公式修正** — setup_params.m
   - Ta_eq 需要除以 i_ratio（与 dyn() 一致）
   - iq0 不应再除 i_ratio
   - 最终 iq0=138.25A, 力矩平衡残差=0

3. **控制约束问题** — Vd 约束 [-50,50] 但 Vd0=-242V
   - 扩大到 [-inf, inf]（Vd 不限）
   - du 约束扩大到 ±500

### 当前状态
- A_cont 特征值：稳定（A(3,3)=-0.043）
- max|eig(A_aug)|=1.0043（积分器）
- quadprog 已去掉，改用解析解 dU=-H\f
- Q_beta=5000, Q_sync=1000
- 正则化=1e-6

### 待解决问题
- MPC 控制器输出仍不够，大部分 Np/Nc 结果相同
- 只有 Np=10,Nc=8 有部分真实结果
- 可能需要进一步调试权重、约束或预测矩阵

- `dual_motor_dynamics.m` — 新建（从 mpc_controller.m 提取）

- `setup_params.m` — 修正平衡点公式，增大权重
- `tune_mpc.m` — 去掉 quadprog，去掉状态缩放，加初始扰动
