## 第1章 绪论（文献综述）

**研究背景（基于原文）：**
- 截至2025年，全球风电累计装机1136GW，海上风电83.2GW，年均增长率超20%
- 我国风电装机占全球46%，新增装机世界第一，海上风电新增占全球50%
- 10MW及以上超大型海上机组已成主流趋势

**单电机方案的4个问题（原文）：**
1. 单电机所需转矩急剧升高 → 体积重量大 → 难装进轮毂
2. 大功率非标电机成本高、维护难度大
3. 无冗余备份，电机故障无法顺桨
4. 复杂工况下动态响应与抗扰动能力不足

**国外双驱应用现状（原文）：**
- 西门子歌美飒 SG 14-222、SG 15-236（14-15MW）：双电机变桨，超级电容后备电源，1ms级通讯同步，SIL3安全等级
- 维斯塔斯 V236-15MW：独立控制双电机转矩，齿圈载荷均匀分配，轴承寿命提升20%以上，支持单电机故障降级运行

**5种同步控制结构对比（原文表格）：**

| 结构 | 耦合强度 | 同步精度 | 抗扰能力 | 适用电机数 | 计算复杂度 |
|------|----------|----------|----------|------------|------------|
| 并行控制 | 无耦合 | 低 | 弱 | 不限 | 低 |
| 主从控制 | 单向弱耦合 | 中 | 中 | 不限 | 低 |
| 交叉耦合 | 双向强耦合 | 高 | 强 | 仅2台 | 中 |
| 偏差耦合 | 全局强耦合 | 高 | 强 | 2台及以上 | 高 |
| 虚拟主轴 | 虚拟柔性耦合 | 中 | 中 | 不限 | 中 |

## 第2章 变桨PMSM电磁设计

**电机基本参数（基于原文）：**

| 参数 | 数值 |
|------|------|
| 额定功率 | 22 kW |
| 额定转速 | 1160 rpm |
| 极对数 | 3（6极） |
| 定子槽数 | 36槽 |
| 定子外径 | 310 mm |
| 定子内径 | 210 mm |
| 转子内径 | 75 mm |
| 铁心长度 | 180 mm |
| 气隙长度 | 1 mm |
| 效率 | 95% |
| 功率因数 | 0.95 |
| 永磁体材料 | N38SH（Br=1.22T，Hc=907kA/m） |
| 转子结构 | 内置式径向，V型磁钢 |
| 定子槽型 | 梨形槽 |
| 绕组形式 | 双层短距叠绕组，节距y=5，60°相带 |

**槽尺寸（原文）：**
- hs0=0.8mm, hs1=1mm, hs2=21.85mm
- bs0=2.5mm, bs1=7.53mm, bs2=10.59mm

**设计选择理由（原文）：**
- **6极36槽**：经典整数槽配合，q=2，磁场分布均匀，谐波含量低，模具通用性强，适合双驱系统对电机互换性的要求
- **梨形槽**：窄槽口+大圆弧槽底，削弱齿槽效应，降低振动噪声，适配长周期免维护
- **双层短距绕组**：节距y=5，可削弱5次和7次谐波，降低转矩脉动
- **内置式径向V型磁钢**：漏磁小，永磁利用率高，机械强度高，正反转电磁特性对称

## 第4章 双电机同步控制

**核心内容：**
1. ADRC替代PI：起动超调从12.5%→基本无超调，恢复时间缩短50%
2. 改进偏差耦合：以全局平均转速为基准，复杂度从n(n-1)降至n
3. 仿真结果：改进偏差耦合+ADRC，扰动下同步误差降低50-67%
