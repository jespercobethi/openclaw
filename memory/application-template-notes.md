# 湖南省研究生科研创新项目申请表 — 结构分析

> 参考：李奔《海上大型风机双驱电动变桨系统研究》
> 2024年12月提交，不资助项目

---

## 📋 申请表结构（共5大部分 + 审批页）

### 一、简表（第1-2页）
- 项目名称、研究类别（基础研究/应用研究/试验发展）
- 研究年限、申请经费（万元）
- 主持人信息：姓名、身份证号、在读层次（硕士）、学科专业、在读学年
- 指导教师：姓名、学历学位、技术职称、研究方向、指导学生数
- 主要研究人员：姓名、身份证号、技术职务、专业、单位
- 项目负责人学习和工作经历（从上大学开始）

**注意**：
- 李奔是研二，申请经费1万元
- 研究人员共6人（含负责人）
- 经历要突出：获奖、竞赛、科研参与

### 二、立项依据（第2-10页）— 最重要的部分
包含：
1. **研究目的和意义** — 为什么要做这个研究
2. **国内外研究现状分析** — 文献综述（要全面、有层次）
3. **发展趋势** — 领域发展方向
4. **应用前景和学术价值** — 能解决什么实际问题
5. **现有研究基础、条件、手段** — 依托平台、实验室
6. **指导教师情况** — 导师背景

**李奔的写法**：
- 研究意义：从能源消耗→海上风电优势→单电机局限→双电机方案
- 文献综述分4个子主题：
  - 2.1 变桨伺服电机研究现状
  - 2.2 多电机控制策略研究现状（4种控制结构对比）
  - 2.3 海上风机双驱变桨系统研究现状
  - 2.4 国内外研究现状总结
- 应用前景：市场数据+国产化替代空间
- 参考文献：46篇

### 三、研究方案（第13-16页）
包含：
1. **研究目标** — 要达到什么目的
2. **研究内容** — 具体做什么（3个方面）
3. **拟解决的关键问题** — 技术难点（3个）
4. **研究方法** — 理论+仿真结合
5. **可行性分析** — 方案可行性、研究基础可行性、条件可行性
6. **创新之处** — 3个创新点

**李奔的写法**：
- 研究目标：设计一套双驱变桨系统
- 研究内容：电机设计 + 同步控制 + 海上动态模型
- 关键问题：电机设计、控制策略选取、动态模型建立
- 创新点：①电机设计 ②ADRC+偏差耦合 ③海上变桨策略优化
- 可行性：三方面论证（方案/基础/条件）

### 四、研究基础（第17-19页）
包含：
1. **研究工作积累** — 前期做了什么（附仿真图）
2. **已取得的研究工作成绩** — 专利、论文等

**李奔的写法**：
- 前期工作：ADRC vs PI对比仿真 + 偏差耦合控制模型（附3张仿真图）
- 已有成绩：1项专利在投

### 五、经费预算（第20页）
- 科研业务费：0.3万（资料、论文出版、专利申请）
- 实验材料费：0.5万（器材耗材）
- 仪器设备费：0
- 相关经费：0.2万（外出交流交通）
- 合计：1.0万

### 审批页（第21页）
- 指导教师意见
- 指导教师承诺
- 研究生院审查及经费保障意见

## 📝 写作要点总结

### 格式要求
- 标题用"一、二、三..."大写数字
- 子标题用"1. 2. 3."或"（1）（2）（3）"
- 参考文献用方括号编号[1][2]...
- 图表要有编号和标题（中文+英文）
- 页码用"— X —"格式

### 内容要点
1. **立项依据要充分**：研究意义（为什么做）+ 文献综述（别人做了什么）+ 现有不足（你的切入点）
2. **文献综述要有层次**：分子主题、按时间线或技术路线梳理
3. **创新点要明确**：3个左右，每个一句话概括+具体说明
4. **可行性要三方面论证**：方案可行、基础可行、条件可行
5. **研究基础要有"干货"**：仿真结果图、已有数据、前期成果
6. **经费预算要合理**：总计1万，分科目列清楚

### 时间规划
- 通常1-1.5年
- 按阶段划分，每阶段2-4个月
- 最后阶段用于论文撰写和结题

## ⚠️ 李奔申请表的问题（写的时候避免）
1. 时间规划有重叠（2024年1-3月和4-8月有交叉）
2. 创新点描述偏笼统，缺乏量化指标
3. 预期成果偏保守（1-2篇论文或1项专利）
4. 没有明确的性能指标（同步精度、响应时间等）
