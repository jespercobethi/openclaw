# 步骤1：Clark变换推导

## 1.1 变换目标

将三相静止坐标系（A、B、C）变换为两相静止坐标系（α、β）。

**目的：** 三相系统有3个自由度，但实际上只有2个独立变量（因为 i_A + i_B + i_C = 0），用两相即可完整描述。

## 1.2 坐标系定义

```
        B轴
         ↑
         |   120°
         |  ↗
         | /
         |/________→ α轴
        /\
       /  \
      /    \
   A轴      C轴
   
   三相绕组在空间上互差120°
   α轴与A轴重合
   β轴超前α轴90°
```

## 1.3 磁动势等效原则

假设三相绕组每相匝数为 N₃，两相绕组每相匝数为 N₂。

三相合成磁动势在α轴和β轴的分量：

```
F_α = N₃ · [i_A · cos(0°) + i_B · cos(120°) + i_C · cos(240°)]
    = N₃ · [i_A - (1/2)·i_B - (1/2)·i_C]

F_β = N₃ · [i_A · sin(0°) + i_B · sin(120°) + i_C · sin(240°)]
    = N₃ · [(√3/2)·i_B - (√3/2)·i_C]
```

两相绕组产生的磁动势：

```
F_α = N₂ · i_α
F_β = N₂ · i_β
```

令两者相等（磁动势等效）：

```
N₂ · i_α = N₃ · [i_A - (1/2)·i_B - (1/2)·i_C]
N₂ · i_β = N₃ · [(√3/2)·i_B - (√3/2)·i_C]
```

## 1.4 匝比选择

**等幅值变换：** 取 N₂/N₃ = 2/3

此时：

```
i_α = (2/3) · [i_A - (1/2)·i_B - (1/2)·i_C]
i_β = (2/3) · [(√3/2)·i_B - (√3/2)·i_C]
    = (1/√3) · (i_B - i_C)
```

## 1.5 Clark变换矩阵

写成矩阵形式：

```
┌    ┐       ┌                    ┐   ┌    ┐
│ i_α │   2   │  1   -1/2   -1/2  │   │ i_A │
│    │ = ─ · │                     │ · │ i_B │
│ i_β │   3   │  0   √3/2  -√3/2  │   │ i_C │
└    ┘       └                    ┘   └    ┘
```

令 Clark 变换矩阵为 C：

```
        ┌                ┐
   C =  │  1   -1/2   -1/2  │  × (2/3)
        │  0   √3/2  -√3/2  │
        └                ┘
```

## 1.6 Clark反变换

由 i_A + i_B + i_C = 0（三相对称），可得：

```
┌    ┐       ┌        ┐   ┌    ┐
│ i_A │       │  1    0  │   │ i_α │
│ i_B │   =   │ -1/2  √3/2 │ · │ i_β │
│ i_C │       │ -1/2 -√3/2 │   └    ┘
└    ┘       └        ┘
```

## 1.7 验证

取三相对称电流：

```
i_A = I_m · cos(θ)
i_B = I_m · cos(θ - 120°)
i_C = I_m · cos(θ + 120°)
```

代入Clark变换：

```
i_α = (2/3)[I_m·cosθ - (1/2)·I_m·cos(θ-120°) - (1/2)·I_m·cos(θ+120°)]
    = (2/3)[I_m·cosθ - (1/2)·I_m·2·cosθ·cos120°]  ← 利用和差化积
    = (2/3)[I_m·cosθ - (1/2)·I_m·2·cosθ·(-1/2)]
    = (2/3)[I_m·cosθ + (1/2)·I_m·cosθ]
    = (2/3)·(3/2)·I_m·cosθ
    = I_m · cosθ  ✓

i_β = (2/3)[(√3/2)·I_m·cos(θ-120°) - (√3/2)·I_m·cos(θ+120°)]
    = (2/3)·(√3/2)·I_m·[cos(θ-120°) - cos(θ+120°)]
    = (2/3)·(√3/2)·I_m·[-2·sinθ·sin(-120°)]
    = (2/3)·(√3/2)·I_m·[2·sinθ·(√3/2)]
    = (2/3)·(3/2)·I_m·sinθ
    = I_m · sinθ  ✓
```

**结论：** Clark变换将三相交流量变换为两相交流量（αβ），幅值不变，相位差90°。

# 步骤2：Park变换推导

## 2.1 变换目标

将两相静止坐标系（α、β）变换为两相旋转坐标系（d、q）。

**目的：** 将交流量变为直流量，便于控制器设计。

## 2.2 坐标系定义

```
        β轴
         ↑
         |     q轴（转子磁场方向）
         |    ↗
         |   / θ_e
         |  /
         | /________→ α轴
        /       ↘
       /    θ_e   d轴（与转子磁场方向垂直）
      /          ↙
                 （d轴滞后q轴90°）
```

**关键定义：**
- d轴（direct axis）：与转子永磁体磁链方向一致
- q轴（quadrature axis）：超前d轴90°电角度
- θ_e：转子电角度（d轴与α轴的夹角）

## 2.3 坐标旋转原理

将αβ坐标系中的向量旋转θ_e角度，使其与dq坐标系对齐。

```
i_d = i_α · cos(θ_e) + i_β · sin(θ_e)
i_q = -i_α · sin(θ_e) + i_β · cos(θ_e)
```

**推导过程：**

设αβ平面上的电流向量 i 与α轴夹角为 φ，则：
```
i_α = |i| · cos(φ)
i_β = |i| · sin(φ)
```

dq坐标系相对于αβ旋转了θ_e，所以 i 在dq坐标系中的分量：
```
i_d = |i| · cos(φ - θ_e)
    = |i| · [cosφ·cosθ_e + sinφ·sinθ_e]
    = i_α · cosθ_e + i_β · sinθ_e  ✓

i_q = |i| · sin(φ - θ_e)
    = |i| · [sinφ·cosθ_e - cosφ·sinθ_e]
    = i_β · cosθ_e - i_α · sinθ_e  ✓
```

## 2.4 Park变换矩阵

```
┌    ┐       ┌                    ┐   ┌    ┐
│ i_d │       │  cosθ_e   sinθ_e  │   │ i_α │
│    │   =   │                     │ · │    │
│ i_q │       │ -sinθ_e   cosθ_e  │   │ i_β │
└    ┘       └                    ┘   └    ┘
```

令 Park 变换矩阵为 P：

```
        ┌                    ┐
   P =  │  cosθ_e   sinθ_e  │
        │ -sinθ_e   cosθ_e  │
        └                    ┘
```

## 2.5 Park反变换

Park矩阵是正交矩阵，其逆等于转置：

```
┌    ┐       ┌                    ┐   ┌    ┐
│ i_α │       │  cosθ_e  -sinθ_e  │   │ i_d │
│    │   =   │                     │ · │    │
│ i_β │       │  sinθ_e   cosθ_e  │   │ i_q │
└    ┘       └                    ┘   └    ┘
```

## 2.6 从ABC到dq的完整变换

将Clark和Park合并：

```
┌    ┐       ┌                          ┐   ┌    ┐
│ i_d │   2   │  cosθ_e    cos(θ_e-2π/3)   cos(θ_e+2π/3)  │   │ i_A │
│    │ = ─ · │                                                │ · │ i_B │
│ i_q │   3   │ -sinθ_e   -sin(θ_e-2π/3)  -sin(θ_e+2π/3)  │   │ i_C │
└    ┘       └                          ┘   └    ┘
```

## 2.7 物理意义

**稳态情况下：**
- i_A, i_B, i_C 是幅值为 I_m、频率为 ω_e 的正弦交流
- 经过Park变换后：i_d, i_q 是**直流量**
- i_d 对应无功分量（励磁分量）
- i_q 对应有功分量（转矩分量）

**为什么这对控制很重要：**
- 交流量 → 直流量，PI控制器可以无静差跟踪
- 转矩 T_e ∝ i_q，控制 i_q 即可线性控制转矩

# 步骤3：PMSM dq坐标系状态空间模型

## 3.1 dq坐标系下的电压方程推导

### 3.1.1 起点：αβ坐标系电压方程

在αβ坐标系中，PMSM的电压方程为：

```
u_α = R·i_α + L_s·(di_α/dt) + e_α
u_β = R·i_β + L_s·(di_β/dt) + e_β
```

其中反电动势：
```
e_α = -ω_e·ψ_f·sin(θ_e)
e_β =  ω_e·ψ_f·cos(θ_e)
```

（这里假设表贴式PMSM，L_d = L_q = L_s）

### 3.1.2 对αβ方程施加Park变换

将 i_α, i_β, u_α, u_β 用 i_d, i_q, u_d, u_q 表示。

由Park变换：
```
i_α = i_d·cosθ_e - i_q·sinθ_e
i_β = i_d·sinθ_e + i_q·cosθ_e
```

对时间求导：
```
di_α/dt = (di_d/dt)·cosθ_e - i_d·sinθ_e·(dθ_e/dt) - (di_q/dt)·sinθ_e - i_q·cosθ_e·(dθ_e/dt)
        = (di_d/dt)·cosθ_e - (di_q/dt)·sinθ_e - ω_e·(i_d·sinθ_e + i_q·cosθ_e)

di_β/dt = (di_d/dt)·sinθ_e + i_d·cosθ_e·(dθ_e/dt) + (di_q/dt)·cosθ_e - i_q·sinθ_e·(dθ_e/dt)
        = (di_d/dt)·sinθ_e + (di_q/dt)·cosθ_e + ω_e·(i_d·cosθ_e - i_q·sinθ_e)
```

### 3.1.3 代入αβ电压方程

```
u_α = R·i_α + L_s·di_α/dt + e_α
```

将 i_α, di_α/dt, e_α 的表达式代入，然后投影到d轴和q轴：

**d轴分量（u_α·cosθ_e + u_β·sinθ_e）：**

经过展开和化简（关键步骤：利用 cos²θ + sin²θ = 1）：

```
u_d = R·i_d + L_s·(di_d/dt) - ω_e·L_s·i_q
```

**q轴分量（-u_α·sinθ_e + u_β·cosθ_e）：**

```
u_q = R·i_q + L_s·(di_q/dt) + ω_e·L_s·i_d + ω_e·ψ_f
```

### 3.1.4 最终dq电压方程

```
┌                                        ┐
│  u_d = R·i_d + L_s·(di_d/dt) - ω_e·L_s·i_q     │  ← d轴
│                                                │
│  u_q = R·i_q + L_s·(di_q/dt) + ω_e·L_s·i_d     │  ← q轴
│        + ω_e·ψ_f                                │
└                                        ┘
```

**物理解读：**
- d轴方程：电阻压降 + 电感压降 + 交叉耦合项（-ω_e·L_s·i_q）
- q轴方程：电阻压降 + 电感压降 + 交叉耦合项（+ω_e·L_s·i_d） + 反电动势（ω_e·ψ_f）

## 3.2 电磁转矩推导

### 3.2.1 电磁功率

PMSM的电磁功率等于q轴电流与反电动势的乘积：

```
P_e = (3/2)·(u_q·i_q + u_d·i_d)  [忽略电阻损耗]
```

在dq坐标系中，电磁功率可表示为：

```
P_e = (3/2)·ω_e·ψ_f·i_q  [表贴式PMSM, id=0时]
```

### 3.2.2 电磁转矩

```
T_e = P_e / ω_m
    = (3/2)·ω_e·ψ_f·i_q / ω_m
    = (3/2)·p·ψ_f·i_q          [因为 ω_e = p·ω_m]
```

对于表贴式PMSM（L_d = L_q），完整的转矩公式为：

```
T_e = (3/2)·p·[ψ_f·i_q + (L_d - L_q)·i_d·i_q]
    = (3/2)·p·ψ_f·i_q          [因为 L_d = L_q，第二项为0]
```

定义转矩常数：**K_t = (3/2)·p·ψ_f**

则：**T_e = K_t · i_q**

**这是矢量控制（id=0）的理论基础！**

## 3.3 运动方程

根据牛顿第二定律（旋转运动）：

```
J·(dω_m/dt) = T_e - T_L - B·ω_m
```

其中：
- J：转动惯量（电机转子 + 折算到电机轴的负载惯量）
- T_L：负载转矩（气动载荷折算到电机轴）
- B：粘性摩擦系数

## 3.4 状态空间模型整理

### 3.4.1 选取状态变量

```
x = [i_d, i_q, ω_m]ᵀ
```

### 3.4.2 从电压方程解出 di/dt

由dq电压方程：

```
di_d/dt = -(R/L_s)·i_d + ω_e·i_q + (1/L_s)·u_d
di_q/dt = -ω_e·i_d - (R/L_s)·i_q + (1/L_s)·u_q - (ω_e·ψ_f)/L_s
```

注意 ω_e = p·ω_m，代入：

```
di_d/dt = -(R/L_s)·i_d + (p·ω_m)·i_q + (1/L_s)·u_d
di_q/dt = -(p·ω_m)·i_d - (R/L_s)·i_q + (1/L_s)·u_q - (p·ω_m·ψ_f)/L_s
dω_m/dt = (K_t/J)·i_q - (B/J)·ω_m - (1/J)·T_L
```

### 3.4.3 连续状态方程

```
dx/dt = A_c·x + B_c·u + E_c·d
```

展开：

```
d ┌    ┐   ┌                              ┐   ┌    ┐     ┌        ┐
──│ i_d │   │ -R/L_s    p·ω_m      0       │   │ i_d │     │ 1/L_s  0 │     ┌    ┐
dt│ i_q │ = │ -p·ω_m   -R/L_s      0       │ · │ i_q │  +  │  0   1/L_s │ · │u_d │
  │ ω_m │   │  0        K_t/J    -B/J      │   │ ω_m │     │  0     0  │   │u_q │
  └    ┘   └                              ┘   └    ┘     └        ┘     └    ┘
                                              ┌    ┐
                                          +   │  0  │ · T_L
                                              │-ψ_f·p·ω_m/L_s│
                                              │-1/J │
                                              └    ┘
```

**注意：** 矩阵 A_c 中含有 ω_m 项，系统是**非线性**的。

### 3.4.4 线性化（在工作点处）

在稳态工作点 (i_d0, i_q0, ω_m0) 处线性化：

```
A_c ≈ ┌                              ┐
      │ -R/L_s    p·ω_m0      0       │
      │ -p·ω_m0   -R/L_s      0       │
      │  0        K_t/J      -B/J     │
      └                              ┘
```

（将 ω_m 视为常数 ω_m0，忽略高阶小量）

### 3.4.5 离散化（前向欧拉法）

采样周期 T_s，用前向欧拉近似：dx/dt ≈ [x(k+1) - x(k)] / T_s

```
x(k+1) = (I + A_c·T_s)·x(k) + B_c·T_s·u(k) + E_c·T_s·d(k)
        = A_d·x(k) + B_d·u(k) + E_d·d(k)
```

其中：

```
A_d = I + A_c·T_s

    ┌                                      ┐
  = │ 1 - R·T_s/L_s     p·ω_m0·T_s     0       │
    │ -p·ω_m0·T_s    1 - R·T_s/L_s     0       │
    │  0              K_t·T_s/J     1 - B·T_s/J │
    └                                      ┘
```

```
B_d = B_c · T_s = ┌ T_s/L_s    0    ┐
                   │  0      T_s/L_s │
                   │  0        0     │
                   └                 ┘
```

```
E_d = E_c · T_s = ┌        0              ┐
                   │ -ψ_f·p·ω_m0·T_s/L_s  │
                   │     -T_s/J            │
                   └                       ┘
```

### 3.4.6 输出方程

```
y(k) = C · x(k)
```

输出为转速和q轴电流：

```
C = ┌          ┐
    │ 0  0  1  │  ← 输出 ω_m
    │ 0  1  0  │  ← 输出 i_q（用于转矩观测）
    └          ┘
```

## 3.5 矢量控制策略（id = 0）

### 3.5.1 控制原理

当 id = 0 时：
```
T_e = K_t · i_q     （线性关系）
```

控制结构：
```
ω_ref ──→ [速度环PI] ──→ i_q* ──→ [电流环PI] ──→ u_q ──→ [逆变器] ──→ PMSM
                                                              ↑
              id* = 0 ──→ [电流环PI] ──→ u_d ─────────────────┘
              
              实际 id, i_q 通过 Park 变换 + 电流采样获得
```

### 3.5.2 电流环解耦

为了消除d轴和q轴之间的交叉耦合，引入前馈解耦：

```
u_d = u_d' - ω_e·L_s·i_q
u_q = u_q' + ω_e·L_s·i_d + ω_e·ψ_f
```

其中 u_d', u_q' 是PI控制器输出。这样d轴和q轴完全解耦，可以独立设计PI参数。

## 4.2 减速齿轮箱模型

### 4.2.1 基本关系

```
桨距角：  β = θ_m / N    [rad]    →  β = θ_m / N × (180/π)  [°]

转矩折算：T_L' = T_aero / (N × η)

其中：
  θ_m：电机转子角度 [rad]
  N：传动比（典型值 1000:1）
  η：传动效率（典型值 0.95）
  T_aero：叶片上的气动转矩 [N·m]
  T_L'：折算到电机轴的负载转矩 [N·m]
```

### 4.2.2 齿轮间隙非线性

```
         输出角 θ_out
            ↑
            │      /  ← 斜率=1（正常传动）
            │     /
            │----/   ← 间隙 Δ
            │   /
            │  /
            │ /
            └────────────→ 输入角 θ_in
```

数学表达：
```
if |θ_in - θ_out| < Δ:
    dθ_out/dt = 0          ← 死区内输出不变
else:
    θ_out = θ_in - Δ·sign(dθ_in/dt)  ← 正常传动
```

其中 Δ 为齿轮间隙（典型值 0.1°）。

## 4.3 气动载荷模型

### 4.3.1 风轮气动转矩

单个叶片上的气动转矩：

```
T_aero = (1/2) · ρ · π · R³ · [Cp(β, λ) / λ] · V²
```

其中：
- ρ = 1.225 kg/m³（空气密度）
- R = 风轮半径 [m]
- V = 来流风速 [m/s]
- λ = ω_r · R / V（叶尖速比）
- ω_r = 风轮转速 [rad/s]
- Cp(β, λ) = 风能利用系数

### 4.3.2 Cp特性曲线

Cp 是桨距角 β 和叶尖速比 λ 的函数，典型特性：

```
  Cp
  ↑
  0.48 ┤      *
  0.44 ┤    *   *
  0.40 ┤   *     *
  0.36 ┤  *       *
  0.32 ┤ *         *
  0.28 ┤*           *
  0.24 ┤             *    β=0°
  0.20 ┤              *
  0.16 ┤               *
  0.12 ┤                *  *
  0.08 ┤                  * *
  0.04 ┤                   **
  0.00 ┼──┬──┬──┬──┬──┬──┬──→ λ
       0  2  4  6  8  10 12

  β增大时，Cp曲线整体下移
```

**Cp经验公式（常用）：**

```
Cp(β, λ) = 0.5176 · (116/λi - 0.4β - 5) · exp(-21/λi) + 0.0068λ

其中：
1/λi = 1/(λ + 0.08β) - 0.035/(β³ + 1)
```

### 4.3.3 气动转矩折算到电机轴

```
T_L = T_aero / (N · η)
    = (1/2) · ρ · π · R³ · [Cp/(λ·N·η)] · V²
```

## 4.4 完整系统状态空间模型

### 4.4.1 单电机变桨伺服系统

状态变量：x = [i_d, i_q, ω_m, β]ᵀ

```
di_d/dt = -(R/L_s)·i_d + (p·ω_m)·i_q + (1/L_s)·u_d

di_q/dt = -(p·ω_m)·i_d - (R/L_s)·i_q + (1/L_s)·u_q - (p·ω_m·ψ_f)/L_s

dω_m/dt = (K_t/J)·i_q - (B/J)·ω_m - T_aero/(N·η·J)

dβ/dt = (1/N) · ω_m · (180/π)
```

### 4.4.2 三电机耦合系统

对于三个变桨电机驱动同一风轮的三个叶片：

状态变量：X = [x₁, x₂, x₃]ᵀ = [i_d1, i_q1, ω_m1, β₁, i_d2, i_q2, ω_m2, β₂, i_d3, i_q3, ω_m3, β₃]ᵀ

```
dX/dt = A_sys·X + B_sys·U + E_sys·D + C_couple
```

其中耦合项 C_couple 表示轮毂对三个叶片的机械耦合力矩。
